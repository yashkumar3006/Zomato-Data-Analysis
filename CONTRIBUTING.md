# Contributing to Zomato Restaurant Data Analysis

Thank you for your interest in contributing! 🍕

## How Can I Contribute?

### 🔍 Data Insights
- Discover new patterns in restaurant data
- Identify interesting correlations
- Propose new analysis angles
- Share industry knowledge

### 📊 Analysis Improvements
- Enhanced data cleaning techniques
- Advanced statistical methods
- Predictive models (ML)
- New visualization approaches

### 🐛 Bug Reports

If you find issues:

1. Check existing issues first
2. Create a detailed report with:
   - Clear, descriptive title
   - Steps to reproduce
   - Expected vs. actual behavior
   - Environment details (Python version, libraries)
   - Screenshots if applicable

### ✨ Feature Suggestions

Have ideas for new analyses?

1. Open an issue describing:
   - What analysis you suggest
   - Why it's valuable
   - Expected insights
   - Data needed

### 📝 Documentation

- Fix typos or unclear explanations
- Add examples or clarifications
- Improve code comments
- Add data dictionary entries

## Getting Started with Development

### 1. Fork & Clone
```bash
git clone https://github.com/YOUR_USERNAME/Zomato-Data-Analysis.git
cd Zomato-Data-Analysis
```

### 2. Create Virtual Environment
```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
```

### 3. Install Dependencies
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 4. Create Feature Branch
```bash
git checkout -b feature/new-analysis
```

### 5. Make Changes & Test
- Modify notebooks or code
- Run cells to verify functionality
- Test visualizations
- Document your changes

### 6. Commit & Push
```bash
git commit -m "Add: description of contribution"
git push origin feature/new-analysis
```

### 7. Open Pull Request
- Clear description of changes
- Link to related issues
- Explain your approach

## Code Guidelines

### Jupyter Notebooks
- Clear markdown headers for sections
- Explanatory comments in code cells
- Document assumptions and decisions
- Use descriptive variable names
- Include visualizations with titles

### Python Code
- Follow [PEP 8](https://www.python.org/dev/peps/pep-0008/)
- Use meaningful variable names
- Add docstrings for functions
- Keep functions focused and reusable
- Add comments for complex logic

### Analysis Standards

When adding new analysis:

1. **Explore the data** — Understand what you're analyzing
2. **Clean & validate** — Handle outliers and missing data
3. **Visualize clearly** — Make insights obvious
4. **Document findings** — Explain what the data shows
5. **Link to business** — Connect to restaurant success

---

## Commit Messages

Use clear, descriptive messages:
- `Add: cuisine popularity analysis`
- `Fix: price outlier handling`
- `Improve: visualization clarity`
- `Refactor: data cleaning code`

---

## Pull Request Process

1. Update README if adding new analyses
2. Add comments explaining your approach
3. Include visualizations where appropriate
4. Test your code thoroughly
5. Request review from maintainers
